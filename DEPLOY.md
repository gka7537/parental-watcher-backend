# Deploy to Render.com

## Steps:
1. Push to GitHub
2. Go to render.com
3. New Web Service
4. Connect GitHub repo
5. Add Environment Variables
6. Deploy!

## Environment Variables:
- MONGODB_URI
- JWT_SECRET
- CLOUDINARY_CLOUD_NAME
- CLOUDINARY_API_KEY
- CLOUDINARY_API_SECRET
- FIREBASE_PROJECT_ID
- FIREBASE_PRIVATE_KEY
- FIREBASE_CLIENT_EMAIL
