# Parental Watcher Backend

Complete parental control system backend with WhatsApp call recording.

## Features
- JWT Authentication
- Device Management
- Screen & Camera Recording (540p)
- WhatsApp Call Monitoring
- SMS Monitoring
- Location Tracking
- App Blocking
- Time Limits
- Remote Commands (18+ commands)
- Cloud Storage (Cloudinary)
- Push Notifications (Firebase FCM)
- Real-time Updates (WebSocket)

## Deploy to Render.com
1. Push this repo to GitHub
2. Connect to Render.com
3. Add environment variables
4. Deploy!
